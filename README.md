# ⚖️ BMI Calculator

“A modern BMI Calculator built using HTML, CSS, and JavaScript to calculate and track body mass index instantly.”  
This project helps users calculate their Body Mass Index instantly based on height and weight inputs.

## 🚀 Features
- Instant BMI calculation
- User-friendly and responsive interface
- Clean and modern UI design
- Built using pure HTML, CSS, and JavaScript
- Beginner-friendly frontend project

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 📌 Project Purpose
This project was created to strengthen JavaScript fundamentals, DOM manipulation, user input handling, and frontend design skills through a practical health-based application.
